# Установка тестовой версии на iPhone через Windows

`Telegram-Native-unsigned.ipa` предназначен для подписи при установке. Сам по себе он не устанавливается нажатием в переписке и не обходит проверку подписи iOS. Установочный файл появляется только после успешной облачной компиляции; этот репозиторий не содержит заранее готовый IPA.

1. На Windows скачать Sideloadly с https://sideloadly.io/ и установить требуемые им компоненты Apple по официальной инструкции
2. Подключить iPhone по USB и подтвердить доверие компьютеру
3. Выбрать iPhone в Sideloadly и перетащить `Telegram-Native-unsigned.ipa`
4. Ввести свой Apple ID непосредственно в Sideloadly и установить приложение. Пароль и коды не передавать разработчику или в чат
5. Если iOS попросит, включить Developer Mode и подтвердить доверие подписи в настройках устройства

Бесплатная подпись обычно действует 7 дней; Sideloadly поддерживает её обновление. Совместимость конкретной сборки с вашим iPhone нужно проверить после установки.

Предварительная версия использует родной интерфейс Telegram iOS. Баланс Stars — локальное демо, реальные покупки в коде заблокированы. Виртуальные подарки ещё не перенесены. Сборка для бесплатной установки не включает расширения; собственная серверная доставка APNs не настроена, поэтому полную работу фоновых уведомлений обещать нельзя.

Каждый пользователь входит самостоятельно. В установочный файл не добавляются аккаунт разработчика, переписка или готовая сессия.
