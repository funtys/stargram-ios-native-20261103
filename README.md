# Облачная сборка нативного клиента для iPhone

Этот небольшой проект получает закреплённые открытые исходники Telegram iOS, применяет подготовленный патч и собирает приложение на macOS в GitHub Actions. Личный Mac не требуется, но сборка выполняется на настоящем облачном macOS с Xcode 27.1.

Запуск только вручную через **Actions → Native iPhone build → Run workflow**. Автоматических запусков при коммитах и обработчиков pull request нет. Выходные файлы сохраняются как артефакт на 3 дня. Публикации в App Store и отправки приглашений другим людям нет.

В настройках репозитория нужны два Actions secrets: `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Значения в исходники и публичные журналы не записываются. Сертификаты Apple и сессия Telegram для сборки неподписанного IPA не нужны.

Режим `iphone-unsigned` собирает ARM64-приложение для настоящего iPhone, проверяет платформу исполняемого файла и отсутствие чужих профилей подписи, сохраняет `Telegram-Native-unsigned.ipa`. Друг устанавливает его с собственной подписью через Sideloadly на Windows; подробности в `INSTALL-IPHONE.md`.

Режим `simulator` собирает отдельный `.app` для симулятора. Он не подходит для установки на iPhone. В свежем симуляторе без аккаунта скрипт снимает только стартовый экран и запись запуска. Вход, сообщения, покупки и чтение пользовательских чатов не автоматизируются.

Сейчас конфигурация подготовлена, но успешная облачная компиляция ещё не подтверждена. Приложение целиком и его поведение на iPhone должны пройти проверку. Виртуальные подарки ещё не перенесены; APNs для этой сторонней сборки не настроен.

Проверить целостность комплекта: `python3 Bootstrap.py --check-only`.

Стандартные macOS-запуски в открытом репозитории бесплатны по правилам GitHub Actions. Для закрытого репозитория используются лимиты аккаунта, затем возможна оплата согласно настройкам бюджета; этот проект не изменяет бюджеты и не подключает оплату. Открытую публикацию исходников нужно согласовать с владельцем до создания публичного репозитория.
